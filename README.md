# ArcGIS 与盆地沉降回剥分析软件

这是一个课程演示型 Web GIS 项目：在原有 GIS 地图、矢量数据和属性管理功能上，增加盆地沉降回剥计算，并把分析结果写回井位要素，用图表、地质剖面和专题地图共同展示。

## 功能流程

1. 在“沉降回剥分析”面板填写从新到老的地层顶深、底深、底界年龄和岩性，可同时输入逐层古水深与海平面变化。
2. `Backstrip.backstrip()` 校验并按年龄整理输入，逐层计算去压实厚度、沉降组成和区间速率。
3. 页面绘制埋藏史、构造沉降曲线，并显示现今与不同地质时期的地层剖面；剖面可以播放或拖动时间滑块查看。
4. 面板调用 GIS 应用接口，将本次分析的末期构造沉降与代表性速率写入目标井位属性 `tectonicSubsidence`、`rate`，刷新属性表、地图符号和弹窗。
5. 回剥结果可以导出为 JSON，便于留档或继续处理。

## 本次回剥相关改动

- 新增无第三方依赖的计算核心，挂载为 `window.Backstrip.backstrip`；支持砂岩、页岩、灰岩、粉砂岩和煤五种岩性的孔隙度参数。
- 对地层深度、年龄、岩性、选项数组类型和长度进行输入校验；地层重新排序时，古水深和海平面数组跟随原始地层行，避免数据错配。
- 按指数孔隙度关系估算平均孔隙度，使用骨架厚度守恒恢复原始厚度；极薄层计算采用数值稳定形式，并输出诊断、警告和逐层审计数据。
- 按简化 Airy 均衡关系拆分总沉降、构造沉降和负载沉降，计算各年龄点之间的构造沉降速率。
- 增加回剥输入面板、地层动态增删、示例数据、结果摘要、区间速率表和 JSON 导出。
- 增加 Chart.js 图表；Chart.js CDN 不可用时使用内置 Canvas 绘图降级。ArcGIS 地图使用 `topo-vector`，提供井位与沉降速率图层、属性弹窗和速率渐变符号。
- 增加地质剖面对比与时间播放，直观展示从现今向老年代逐层去除沉积负载的重建过程。
- 将回剥结果接入既有 GIS 数据流：写入目标井位属性并复用项目的保存、重载和属性表刷新机制。
- 添加回剥算法测试和 GIS 交互/数据持久化测试。

## 运行

需要 Python 3.8 或以上版本。回剥计算本身不依赖 Python 包或 npm；ArcGIS 地图和 Chart.js 图表由 CDN 加载，因此首次运行时浏览器需要能够访问相应 CDN。Chart.js 不可用时曲线图会降级绘制，ArcGIS 地图仍需要 ArcGIS CDN。

在项目根目录运行：

```powershell
python server.py 8000
```

然后打开 `http://127.0.0.1:8000/`，进入“沉降回剥分析”面板并载入示例数据即可演示。

## 测试

需要 Node.js。运行：

```powershell
node --test --test-isolation=none tests/backstrip.test.js tests/interaction.test.js
```

当前测试覆盖核心算法与部分 GIS 数据交互；没有覆盖完整浏览器操作的端到端自动化测试。

## 计算口径与适用范围

孔隙度按 `φ(z) = φ0 × exp(-c × z)` 变化，岩性参数如下：

| 岩性 | `φ0` | `c (m⁻¹)` | 颗粒密度 `ρg (kg/m³)` |
| --- | ---: | ---: | ---: |
| sandstone（砂岩） | 0.49 | 0.27e-3 | 2650 |
| shale（页岩） | 0.63 | 0.51e-3 | 2720 |
| limestone（灰岩） | 0.60 | 0.55e-3 | 2710 |
| siltstone（粉砂岩） | 0.56 | 0.39e-3 | 2680 |
| coal（煤） | 0.70 | 0.80e-3 | 1300 |

对厚度为 `h`、顶底深分别为 `zt` 和 `zb` 的层段，先计算 `φAvg = [φ(zt) - φ(zb)] / [c × h]`，骨架厚度为 `h × (1 - φAvg)`，原始厚度为 `h × (1 - φAvg) / (1 - φ0)`。程序对极薄地层采用等价的数值稳定算法，并将平均孔隙度限制在物理范围内；如果发生限制，会在诊断信息中报告。

令 `H0` 为从新到老累计的去压实原始厚度，简化 Airy 公式的默认密度为 `ρm = 3330`、`ρw = 1030`、统一参考沉积物密度 `ρs = 2500 kg/m³`。逐年龄点计算：

```text
总沉降       = H0 + 古水深 - 海平面
负载沉降     = H0 × (ρs - ρw) / (ρm - ρw)
构造沉降     = H0 × (ρm - ρs) / (ρm - ρw) + 古水深 - 海平面
总沉降       = 负载沉降 + 构造沉降
区间速率     = 相邻年龄点构造沉降差 / 年龄差（m/Ma）
```

岩性颗粒密度会输出到逐层结果中用于检查，但当前公式仍使用统一的 `ρs`，并未根据地层组合重新计算混合沉积物密度。计算接口为 `Backstrip.backstrip(formations, options)`；结果包含 `burialHistory`（埋藏深度与水深）、`tectonicSubsidence`（总沉降、构造沉降、负载沉降）、`rates`（相邻年龄点的速率）、`summary`（整体指标）、`formationResults`（逐层压实审计数据）、`diagnostics`（输入重排、地层间断和异常提示）以及所用 `constants`。

模型没有包括弹性岩石圈挠曲、热沉降、侵蚀剥蚀恢复、随时间演化的压实耦合或横向地层厚度变化，因此适合课程展示、方法演示和初步敏感性分析，不应替代经校准的专业盆地模拟。面板中的井位速率是当前这组地层结果的平均区间速率；当前演示工作流把同一套输入分析结果写给所选目标井位，并非为每口井独立建立一套地层柱。若需比较真实空间沉降差异，应为每口井录入其自身的地层和年龄数据后分别计算。

随仓库提供的松辽井位仅为虚构训练坐标。地图上的点位和颜色只用于演示 GIS 与回剥结果联动，不代表实测地质结论或真实盆地沉降梯度。正式分析请替换为有来源说明的井位与地层数据。
