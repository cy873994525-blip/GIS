# 成员 D：数据库与空间分析模块完成说明

## 1. 任务目标

在现有 GIS 矢量数据编辑 Demo 上补充空间分析能力，让用户可以在浏览器中完成距离、面积、缓冲区和相交查询，并把分析结果落回当前数据集，便于后续继续编辑、筛选和导出。

## 2. 完成内容

### 2.1 后端空间分析接口

server.py 新增三个接口：

| 接口 | 请求 | 结果 |
| --- | --- | --- |
| POST /api/spatial/measure | operation=distance/area、feature_id | 数值、单位、坐标系提示 |
| POST /api/spatial/buffer | feature_id、正数 distance | 新生成的 GeoJSON 缓冲区要素 |
| POST /api/spatial/intersects | feature_id | 当前数据集中所有相交要素 |

接口复用原有的 GeoJSON 校验、当前数据集读取和原子写入逻辑。缓冲区生成后自动写入当前 GeoJSON，保留 source_id、distance 和 distance_unit 等分析元数据。

### 2.2 距离与面积

- WGS 84 经纬度数据：距离使用 Haversine 球面距离；面积使用经纬度球面环面积近似，结果分别为 m 和 m²。
- 模拟 / 投影数据：距离使用平面欧氏长度；面积使用鞋带公式，结果单位跟随输入坐标。
- 点要素的距离为 0；面积按钮对点或线会返回后端的类型提示，而不会伪造面积值。

### 2.3 缓冲区

- Point：生成 48 段近似圆形 Polygon。
- LineString：生成带圆形端帽和折点处理的 Polygon。
- Polygon：对外环向外偏移，对洞环向内偏移；过窄的洞在缓冲后消失。
- MultiLineString / MultiPolygon：按组件生成 MultiPolygon。
- WGS 84 输入先用以要素中心为原点的方位等距局部投影计算，再反投影回经纬度，避免直接把“米”当成经度差。

### 2.4 相交查询

查询会检测：

1. 线段与线段相交；
2. 点落在线段上；
3. 点落在 Polygon 外环内且不在洞内；
4. Polygon 与 Polygon 的边界相交或互相包含。

查询结果会与地图、右侧选中要素表和底部属性表联动。

### 2.5 前端操作面板

右侧新增“空间分析 / MEMBER D”面板：

1. 点选地图要素，或在“分析要素”下拉框中选择要素；
2. 点击“测量距离”或“测量面积”；
3. 输入缓冲距离，点击“生成缓冲区”；
4. 点击“查询相交”，系统会高亮源要素及所有相交要素。

缓冲区会自动进入“空间分析”图层，并可以像普通要素一样编辑、删除、导出。

## 4. 已知限制与后续方向

- 当前实现坚持零第三方依赖，缓冲区属于轻量几何近似；复杂自交、多洞拓扑和相邻 MultiPolygon 的融合建议后续接入 Shapely / GEOS。
- .prj 当前主要用于坐标系提示，未做完整 EPSG 投影转换；投影 Shapefile 的面积 / 距离仍使用其原始平面单位。
- 当前“数据库”仍是项目 data/ 目录中的 GeoJSON 数据集目录。后续可将这三个接口的读写层替换成 PostGIS，并增加空间索引。
